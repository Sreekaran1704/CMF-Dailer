# DialHack

Turns the Smart Dial on the CMF Buds Pro 2 case into a general-purpose input device on macOS and Android, and logs every twist and press for fidget analytics. All local, no network.

**Status:** Phase 0 (sniffers). See [docs/findings.md](docs/findings.md) for the test protocol and results.

- [mac/README.md](mac/README.md): macOS sniffer build, run, permissions
- [android/README.md](android/README.md): Android sniffer build, run, permissions
- [analytics/sniffer_report.py](analytics/sniffer_report.py): turns sniffer logs into findings tables
- [docs/BRIEF.md](docs/BRIEF.md): full project brief
